# 晨雾迷径

一款基于 Canvas 2D 的 2D 迷宫探索游戏，画风极简优雅，关卡难度递增，融合探索、收集、计时与机关解谜。

## 特性

- 🎨 **6 个独立主题**：晨曦 / 薄荷 / 黄昏 / 深海 / 极光 / 终局，每关一套配色
- 🎮 **网格步进缓动**：移动手感顺滑，碰撞反馈细腻
- ⏱ **多元玩法**：收集钥匙、限时挑战、视野缩限、传送门（终局）
- 🔊 **完整音效系统**：基于 Howler.js，支持音乐/音效独立调节，缺资源时自动用 Web Audio 合成
- 💾 **本地存档**：通关进度、最佳用时、星级评分
- 📱 **桌面 / 移动**：支持键盘 WASD/方向键 + 触屏滑动

## 快速开始

```bash
# 安装依赖
pnpm install   # 或 npm install

# 启动开发服务器
pnpm dev       # 默认 http://localhost:5173

# 构建生产版本
pnpm build
pnpm preview
```

## 操作

| 按键 | 行为 |
|---|---|
| `W A S D` / 方向键 | 移动 |
| `Shift` | 短冲刺（3 秒冷却，连续 4 步加速） |
| `Esc` / `P` | 暂停菜单 |
| `M` | 静音切换（也可点 HUD 右上角图标） |
| 触屏滑动 | 移动 |

## 关卡

| 关卡 | 主题 | 尺寸 | 机制 |
|---|---|---|---|
| 1 晨曦 | 米白米杏 | 11×11 | 教学（基础移动） |
| 2 薄荷 | 清新冷淡 | 15×15 | 收集 3 把钥匙 |
| 3 黄昏 | 暖橙怀旧 | 19×19 | 视野缩小 + 钥匙 + 地图碎片 |
| 4 深海 | 冷静神秘 | 23×23 | 倒计时 75s + 沙漏 +10s |
| 5 极光 | 梦幻紫粉 | 27×27 | 综合机关（更多钥匙、限时、限视野） |
| 6 终局 | 暗夜焰红 | 31×31 | 终极挑战 |

## 项目结构

```
src/
├── main.ts                 入口
├── styles.css              全局样式
├── config/
│   ├── theme.ts            6 关主题配色
│   └── levels.ts           关卡配置
├── core/
│   ├── Game.ts             游戏主控制器（状态机 + 主循环）
│   ├── Renderer.ts         Canvas 渲染（墙体/玩家/雾气/动效）
│   ├── Audio.ts            音频管理（Howler + Web Audio fallback）
│   ├── Input.ts            键盘 / 触屏输入
│   ├── Storage.ts          localStorage 存档
│   └── utils.ts            缓动 / RNG / 时间格式化
├── maze/
│   ├── Generator.ts        递归回溯生成 + BFS
│   └── LevelBuilder.ts     关卡运行时构建（迷宫 + 实体）
├── entities/
│   └── Player.ts           玩家（网格步进缓动 + 冲刺）
├── fx/
│   └── Particles.ts        粒子系统
└── ui/
    ├── Hud.ts              游戏内 HUD
    ├── Minimap.ts          小地图
    └── Overlays.ts         主菜单 / 关卡选择 / 暂停 / 结算 / 设置
```

## 音效

详见 [`public/audio/README.md`](./public/audio/README.md)。

**重要**：游戏在没有音频文件的情况下，会自动用 Web Audio API 合成简单音效，**确保零配置即可玩**。要获得最佳听感，按 README 的清单下载并放置真实音频文件即可。
